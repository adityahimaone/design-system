/* Bluewater Freight — three-layer tokens.
   primitives → semantic → component. Namespaced --bw- so the case never touches
   the host's tokens.

   Deep (the night ground) is the page default. Fog is a *scope*, not a second
   palette: `html[data-bluewater='light']` re-points the same semantic names at
   the daylight primitives, so no component knows which ramp it is on.

   Regenerate the page's swatches from features/bluewater/tokens.json; the two
   files must never disagree. */
